# ❤️ MEG LOVE Backend

Username-based call server with WebRTC signaling.

## Deploy on Render
1. Create new Web Service → connect this repo
2. render.yaml auto-detected → click Create
3. Done! Live at https://meglove-backend.onrender.com

## API
- POST /api/register    { phone, username }
- GET  /api/lookup?username=xxx
- WS   /ws?userId=ID
